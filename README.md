# Яндекс Навигатор на приборке Changan UNI-V (DLX)

Пошаговая инструкция, как вывести навигацию Яндекс Навигатора на приборную панель Changan UNI-V
**без root и без перепрошивки** — только по ADB и с одним небольшим приложением-мостом.

Что получается:

- **Normal Navi** (меню приборки на руле) — стрелка манёвра, расстояние и улица в окне навигации приборки;
- **En Navi** — полная карта Яндекса на приборке, во всю видимую область;
- **жест тремя пальцами** по экрану головного устройства (ГУ): справа налево — карта на приборку,
  слева направо — карта обратно на ГУ (работает, когда приборка в режиме En Navi);
- карта может оставаться на экране ГУ, пока на приборке стрелка.

Как это устроено внутри — [docs/how-it-works.md](docs/how-it-works.md).

## На чём проверено

| | |
|---|---|
| Автомобиль | Changan UNI-V 1.5T, 2024, комплектация **DLX**, официальный дилер |
| ГУ | Android 9, MT8666, прошивка `SWC.281.001925_20230721` |
| Яндекс Навигатор | **31.1.5** |

На других комплектациях и прошивках может не работать или работать частично — пишите в Issues, что получилось.
С Яндекс Навигатором 17.x стрелка на приборке будет, только пока сам Яндекс не открыт на экране ГУ.

## Что понадобится

- компьютер с [Android Platform Tools](https://developer.android.com/tools/releases/platform-tools) (`adb`);
- кабель **USB-A ↔ USB-A** (разъём под консолью) и, если у компьютера только USB-C, переходник USB-C → USB-A
  с передачей данных (прямой кабель USB-C ↔ USB-A, по опыту, не работает);
- APK моста — из раздела [Releases](../../releases) (`ClusterBridge.apk`) и файл
  [`bridge/helper.sh`](bridge/helper.sh) из этого репозитория;
- APK Яндекс Навигатора 31.x, если на ГУ стоит старая версия (например, скачать через RuStore на телефоне
  или с официального сайта; у ГУ нет интернета — ставится по ADB).

## 1. Включить ADB на ГУ

1. На ГУ откройте приложение **«Телефон»**, наберите `*#*#888` и нажмите вызов.
2. Введите пароль инженерного меню `369875`.
3. Пункт **USB切换** → кнопка **切换为ADB模式** (режим ADB).
4. Подключите кабель к компьютеру и проверьте:

```bash
adb devices
```

В списке должно появиться устройство со статусом `device`.

Оболочка ADB на ГУ спрашивает пароль: при `adb shell` появится `please input verify password` — введите
`adb36987`. Все команды в шагах ниже выполняются **внутри** `adb shell` после ввода пароля, если не сказано иное.

## 2. Обновить Яндекс Навигатор (если версия ниже 31)

Версию можно посмотреть в настройках Android → Приложения. Обычный `adb install` на ГУ не работает, поэтому:

```bash
adb push yandexnavi.apk /data/local/tmp/ya.apk
```

```bash
adb shell
```

```sh
pm install -r /data/local/tmp/ya.apk
rm /data/local/tmp/ya.apk
```

Ставьте только APK, подписанный Яндексом: тогда он встанет поверх текущей версии и сохранит маршруты и аккаунт.

## 3. Установить мост и помощника

На компьютере:

```bash
adb push ClusterBridge.apk /data/local/tmp/cb.apk
```

```bash
adb push helper.sh /data/local/tmp/helper.sh
```

В `adb shell`:

```sh
pm install -r -t /data/local/tmp/cb.apk
rm /data/local/tmp/cb.apk
```

## 4. Выдать мосту права

В `adb shell`, по одной команде:

```sh
# окно поверх второго дисплея (видеовход приборки)
appops set com.test.clusterbridge SYSTEM_ALERT_WINDOW allow

# чтение уведомления Яндекса (стрелка, когда Яндекс свёрнут)
cmd notification allow_listener com.test.clusterbridge/com.test.clusterbridge.HintListener

# служба специальных возможностей: читает ТОЛЬКО окно Яндекс Навигатора (стрелка, когда Яндекс на экране)
s=com.test.clusterbridge/com.test.clusterbridge.YaA11y; v=$(settings get secure enabled_accessibility_services); case "$v" in *$s*) ;; ""|null) settings put secure enabled_accessibility_services $s ;; *) settings put secure enabled_accessibility_services "$v:$s" ;; esac; settings put secure accessibility_enabled 1

# постоянный ADB по сети: через него мост сам запускает помощника после загрузки ГУ
setprop persist.adb.tcp.port 5555
```

> ⚠️ **Про ADB по сети.** После этого ГУ всегда слушает порт 5555 в любой сети Wi-Fi, к которой подключено.
> Подключиться к оболочке сможет любой, кто знает пароль ADB (а он общий для этих ГУ). Если это неприемлемо —
> пропустите эту команду: тогда после каждой перезагрузки ГУ помощника придётся запускать вручную (см. шаг 5),
> а без него не будет работать перенос полной карты в En Navi.

Выйдите из `adb shell` (`exit`) и включите ADB по сети сразу, без перезагрузки:

```bash
adb tcpip 5555
```

## 5. Запустить мост и проверить

Откройте на ГУ приложение **ClusterBridge** (иконка в списке приложений; окно не появится — мост работает в фоне)
или в `adb shell`:

```sh
am start -n com.test.clusterbridge/.MainActivity
```

Проверка — в `adb shell` через несколько секунд:

```sh
logcat -d | grep ClusterBridge
```

Должны быть строки `подписка на запрос видео приборки оформлена`, `подписка на жесты оформлена`
и `помощник запущен через локальный ADB`.

Если последней строки нет (например, вы пропустили постоянный ADB по сети), запустите помощника вручную:

```sh
(setsid nohup sh /data/local/tmp/helper.sh >/dev/null 2>&1 </dev/null &); sleep 2
```

## 6. Вернуть USB в штатный режим

В инженерном меню (`*#*#888`, пароль `369875`) → **USB切换** → **切换为U盘模式**, отключите кабель.
Это обязательно: связь ГУ с приборкой идёт по внутреннему USB-Ethernet и в режиме ADB не работает.

## Как пользоваться

1. Постройте маршрут в Яндекс Навигаторе и нажмите «Поехали».
2. В меню приборки (кнопками на руле) выберите **Normal Navi** — стрелка, метры и улица.
3. **En Navi** — на приборку переезжает полная карта Яндекса. На ГУ остаётся то, что было открыто.
4. Тремя пальцами по экрану ГУ: **слева направо** — карта возвращается на ГУ, на приборке стрелка;
   **справа налево** — карта снова на приборке. Жест работает только в режиме En Navi.
5. Normal Navi или выход из навигации на приборке — карта сама возвращается на ГУ.

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| Меню Normal/En Navi на приборке сразу закрывается | Мост не запущен — откройте ClusterBridge на ГУ; USB должен быть в режиме U |
| В Normal Navi пустой квадрат | Нет активного маршрута в Яндексе, либо Яндекс 17.x открыт на экране (обновите до 31.x) |
| En Navi: стрелка вместо карты, карта не переезжает | Не запущен помощник — см. конец шага 5 |
| После перезагрузки ГУ ничего не работает | Откройте ClusterBridge на ГУ; если не помогло — пишите в Issues |
| Нет улицы под стрелкой | Яндекс сам не даёт название (дорога без имени) — показывается только направление |

Логи для Issues: `adb shell`, затем `logcat -d | grep -E "ClusterBridge|Double-"` и `cat /data/local/tmp/helper.log`.

## Ограничения

- Режим приборки (Normal / En Navi / выключено) выбирается только меню на руле: команду на его смену приборка не принимает.
- После обновления Яндекс Навигатора стрелка может пропасть, если Яндекс поменяет разметку своего уведомления или окна.
- Автозапуск после полной перезагрузки ГУ пока проверен не до конца.

## Как удалить

ГУ не даёт удалить приложение по ADB — удалите **ClusterBridge** в настройках Android → Приложения. Затем в `adb shell`:

```sh
setprop persist.adb.tcp.port ""
rm /data/local/tmp/helper.sh /data/local/tmp/helper.log /data/local/tmp/helper.pid
```

## Сборка из исходников

[`bridge/build.sh`](bridge/build.sh) — без Gradle, нужны JDK 17 и Android SDK (build-tools, platform android-36).
Ключ подписи создаётся при первой сборке. Установить свою сборку поверх версии из Releases не выйдет (другой ключ) —
сначала удалите установленный мост.
